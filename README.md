# VoxyShot

**VoxyShot** は、Minecraft で **4K・8K などの高解像度スクリーンショット** を撮影できる Fabric 用クライアント MOD です。
遠景描画 MOD **[Voxy](https://modrinth.com/mod/voxy)** に対応しており、遠くの地形（LOD）が読み込み終わるまで自動で待ってから撮影するため、遠景までくっきりした一枚を撮ることができます。

モニターの解像度に関係なく、設定した解像度で撮影できます。

---

## 主な機能

- 📸 **高解像度撮影** — 1080p / 1440p / 4K / 5K / 8K のプリセット、または好きな解像度を指定して撮影
- 🏔️ **Voxy 対応** — 遠景 LOD の読み込み完了を自動で待ってから撮影
- ✨ **LOD 品質ブースト** — 撮影時だけ Voxy の遠景を一時的に高精細化（撮影後は自動で元に戻ります）
- 🙈 **HUD 自動非表示** — 照準や手を隠したきれいなスクリーンショット
- ⌨️ **F2 キー置き換え（任意）** — いつもの F2 キーで高解像度撮影できるようにする設定
- 🌐 日本語 / 英語対応

## 動作環境

| 項目 | 必要なもの |
|---|---|
| Minecraft | 26.1.2 〜 26.3 |
| MOD ローダー | [Fabric Loader](https://fabricmc.net/) 0.16.0 以上 |
| Java | 25 以上 |

### あると便利な MOD（任意）

| MOD | 説明 |
|---|---|
| [Voxy](https://modrinth.com/mod/voxy) | 遠景描画 MOD。導入すると遠景 LOD の読み込み待ちと品質ブーストが有効になります。Voxy なしでも高解像度撮影はできます。 |
| [Mod Menu](https://modrinth.com/mod/modmenu) | MOD 一覧画面から VoxyShot の設定画面を開けるようになります。 |

> VoxyShot はクライアント専用 MOD です。サーバーに入れる必要はなく、マルチプレイのサーバーでも使えます。

## インストール方法

1. [Fabric Loader](https://fabricmc.net/use/installer/) を Minecraft にインストールします。
2. VoxyShot の `.jar` ファイルをダウンロードします。
3. `.minecraft/mods` フォルダに `.jar` ファイルを入れます。
   （必要に応じて Voxy や Mod Menu も同じフォルダに入れてください）
4. Fabric のプロファイルで Minecraft を起動します。

---

## 使い方

### 撮影する

1. ワールドに入り、撮りたい景色の方を向きます。
2. **`F9`** キーを押します。
3. チャットに「高解像度スクリーンショットを撮影中…」と表示されます。
   撮影中は画面が一時的に乱れたり、動作が重くなったりしますが正常です。**撮影が終わるまでなるべく動かずに待ってください。**
4. 撮影が終わるとチャットに保存先のファイル名が表示され、画面は元に戻ります。

撮影した画像は、通常のスクリーンショットと同じ **`.minecraft/screenshots`** フォルダに保存されます。

> 💡 Voxy を入れている場合、遠景の読み込みが落ち着くまで待ってから撮影します。景色や設定によっては数十秒かかることがあります。

### キー操作

| キー | 動作 |
|---|---|
| `F9` | 高解像度スクリーンショットを撮影 |
| `F10` | VoxyShot の設定画面を開く |

キーは Minecraft の「設定 → 操作設定 → キー割り当て」から変更できます。

---

## 設定

`F10` キー、または Mod Menu から設定画面を開けます。

| 設定項目 | 説明 | 初期値 |
|---|---|---|
| 解像度プリセット | 撮影する解像度を選びます。<br>1080p (1920×1080) / 1440p (2560×1440) / 4K (3840×2160) / 5K (5120×2880) / 8K (7680×4320) / Custom | 4K |
| カスタム横幅・縦幅 | プリセットで「Custom」を選んだときに表示されます。好きな解像度をピクセル単位で入力します。 | 3840 × 2160 |
| Voxy LOD品質ブースト | 撮影時だけ遠景をどれだけ細かく描画するかの倍率です（1.0x / 1.5x / 2.0x / 3.0x / 4.0x）。大きいほど遠景がきれいになりますが、撮影に時間がかかり、VRAM も多く使います。 | 2.0x |
| 通常のF2キーを高解像度化 | ON にすると、バニラの F2 キーでも高解像度撮影になります。 | OFF |
| 撮影時にHUD（照準・手）を非表示 | ON にすると、照準・手・ホットバーなどを隠して撮影します。 | ON |
| LOD読み込み最大待機時間 | 遠景の読み込みを最大何秒待つかです（15 / 30 / 60 / 120 / 300 秒）。この時間を過ぎると、読み込みが途中でも撮影します。 | 60 秒 |

設定は `.minecraft/config/voxyshot.json` に保存されます。

## よくある質問・トラブルシューティング

**Q. 「Voxy LODの読み込みが○秒以内に完了しませんでした」と表示された**
遠景の読み込みが時間内に終わらなかったため、途中の状態で撮影されました。遠景が粗い場合は、設定の「LOD読み込み最大待機時間」を長くするか、「Voxy LOD品質ブースト」を下げてみてください。

**Q. 撮影中にゲームが重くなる・止まったように見える**
高解像度で描画しているため正常な動作です。特に 8K や高いブースト倍率では時間がかかります。撮影が終わるまでお待ちください。

**Q. 撮影に失敗する・ゲームがクラッシュする**
解像度が高すぎてグラフィックメモリ（VRAM）が足りない可能性があります。解像度プリセットを下げるか、LOD品質ブーストを下げてお試しください。

**Q. Voxy がなくても使える？**
使えます。その場合は遠景の待機やブーストを行わず、通常の描画のまま高解像度で撮影します。

**Q. F2 キーで撮影したい**
設定画面の「通常のF2キーを高解像度化」を ON にしてください。

**Q. 他のシェーダー MOD などと一緒に使える？**
すべての MOD との組み合わせは確認できていません。うまく動かない場合は、他の MOD を外して試してみてください。

## 不具合報告

不具合を報告するときは、次の情報があると助かります。

- Minecraft / Fabric Loader / VoxyShot / Voxy のバージョン
- 一緒に入れている MOD の一覧
- `.minecraft/logs/latest.log`（クラッシュした場合は `crash-reports` フォルダ内のファイルも）
